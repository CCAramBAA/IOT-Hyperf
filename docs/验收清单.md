# Linux 虚拟机验收清单

在 Linux 虚拟机上执行以下步骤，确认平台可以正常运行。任何一步失败，请把终端输出发回。

## 1. 克隆与启动

```bash
git clone git@github.com:CCAramBAA/IOT-Hyperf.git
cd IOT-Hyperf
docker compose up -d --build
docker compose ps
```

期望结果：`mysql`、`redis`、`backend`、`frontend` 四个容器全部为 `Up`（healthy/started）。

## 2. 验证数据库

```bash
docker compose exec mysql mysql -uiot -piot123456 iot_platform -e "SHOW TABLES;"
```

期望结果：能看到 `device_data` 表。

## 3. 验证后端接口

```bash
# 新增
curl -X POST http://localhost:9501/device/data \
  -H "Content-Type: application/json" \
  -d '{"device_id":"dev001","temp":25.5,"humidity":60}'

# 列表 / 按设备筛选
curl http://localhost:9501/device/data
curl "http://localhost:9501/device/data?device_id=dev001"

# 修改（把返回的 id 填到路径里）
curl -X PUT http://localhost:9501/device/data/1 \
  -H "Content-Type: application/json" \
  -d '{"temp":26.8}'

# 删除
curl -X DELETE http://localhost:9501/device/data/1
```

期望结果：新增/修改/删除返回 `"code":200`；空 body 新增返回 `"code":400`；删除不存在的 id 返回 `"code":404`。

## 4. 验证前端页面

浏览器打开：

- 本机操作：http://localhost:8080
- 其他电脑操作：http://虚拟机IP:8080（先执行 `sudo ufw allow 8080/tcp`，云服务器还要放行安全组）

操作流程：新增一条数据 → 刷新页面确认还在 → 修改 → 删除。

## 5. 端口说明

| 服务 | 端口 |
|------|------|
| Web 管理端 | 8080 |
| 后端 API | 9501 |
| MySQL | 3306 |
| Redis | 6379 |

前端页面会自动把 `/api` 请求代理到后端，正常使用只需要 8080。
